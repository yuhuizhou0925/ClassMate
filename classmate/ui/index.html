设置

回答模型

截图题用这个模型（要能看图）；留空 = 和普通回答同一个模型。
截图里的代码题、需要写代码时用这个语言；题目给了代码（找 bug、改错）时修正版保持原语言。留空 = 跟随题目。

语音识别

专业词汇与纠错

告诉语音识别这些词会出现，口音重时也更容易认对。识别服务每次最多接受 100 个词：每次录音会先放你的词，再从内置词库里挑最近说过的、课件里出现的词。
某个词总被识别错时加一条，显示和发给模型前会自动替换（不区分大小写，只替换完整的词）。

窗口

只对原生窗口有效（浏览器模式无效）。少数会议软件可能不认这个设置，第一次用时请先确认一下。

收音

电脑内置声音 = 电脑正在播放的声音（Zoom、腾讯会议、网课视频），比麦克风清楚得多。电脑里没声音、你在说话时自动切到麦克风；两边都安静时不送声音，免得把杂音识别成文字。Mac 需要“屏幕录制”权限（截图已经在用）。

授权

当前授权
只有主授权码登录时能看到这里。生成的授权码到期后自动失效，用它登录的人不能再生成授权码。

快捷键

点右边的按钮，再按新按键或组合键（如 ⌃⌥S）。截图、框选、收录这三个键在其他软件里也生效；收录键可以只是一个修饰键（按住 Ctrl）。录框选键时按 ⌫ = 不用。方向键固定用来移动窗口；⌘Q、⌘W、⌘⇧3/4 这类系统快捷键会被 macOS 先拦走，别用。
